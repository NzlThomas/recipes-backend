**EN COURS**

Ce repository est le backend d'une application d'ajout de recettes de cuisine, développée dans le but de mettre en pratique Typescript tout en adoptant une méthologie de TDD à l'aide de Vitest.

L'objectif de l'application est de permettre à chaque utilisateur de gérer ses propres recettes de cuisine et de sélectionner aléatoirement un plat en 1 clic selon différents critères (Par exemple : entrée/plat/dessert, viande, poisson, légumes, féculents).

### Stack

- TypeScript
- Vitest
- Node.js
- Express
- PostgreSQL
- Prisma
- JWT

<br />

**NOTE : Le projet reste actuellement en cours de construction. Il est donc sujet à de multiples changements au fil du temps.**
